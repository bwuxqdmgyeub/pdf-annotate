Frequently asked questions

Quick answers about pdf-annotate and the Windows release.

Is pdf-annotate really free?+
Yes. pdf-annotate is free and open source. You can download the Windows build, use every annotation and form-filling feature, and inspect or contribute to the source code on GitHub.
Do my PDFs get uploaded to a server?+
No. All parsing, rendering and editing runs locally on your Windows machine. Nothing is uploaded, so confidential contracts and internal documents stay private.
Which Windows versions are supported?+
The current release targets Windows 10 and Windows 11 (64-bit). A portable build is also included in the download package for users who prefer not to install anything.
Will annotations stay editable after export?+
By default exports are flattened so annotations display identically everywhere. You can also save the project file to keep text, ink and stamps editable for future revisions.
